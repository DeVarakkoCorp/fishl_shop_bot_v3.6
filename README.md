# Fishl Shop Bot v3.5

Telegram-бот магазина с прайсами, заказом зачистки и панелью менеджеров.

## Возможности клиента
- 💰 Прайсы по регионам
- 🧹 Заказ зачистки: регион → процент
- 🔐 После выбора услуги бот сразу запрашивает email, затем пароль и Telegram-юзернейм
- ✉️ Email проверяется на формат адреса электронной почты
- 🔢 Код подтверждения принимается только если сообщение содержит цифры
- ⚠️ После ввода данных показывается подтверждение заказа
- 📞 Связь с менеджером

## Данные для входа
После подтверждения заказа бот отправляет в чат менеджеров отдельное сообщение с логином, паролем и кодом подтверждения.

**Важно:** логин, пароль и код не записываются в `orders.db` и хранятся только в оперативной памяти бота до оформления заказа. Однако сообщение в Telegram-чате менеджеров само по себе остаётся в истории Telegram. Поэтому доступ к чату менеджеров должен быть строго ограничен, а после выполнения заказа рекомендуется удалить сообщение с данными и изменить пароль аккаунта.

## Возможности менеджеров
Заказы автоматически сохраняются в `orders.db` (SQLite) и отправляются в `ADMIN_CHAT_ID`.

В сообщении заказа есть кнопки:
- 🟡 Взять заказ
- 🔵 В работу
- ✅ Выполнен
- ❌ Отменить

Команды в чате менеджеров:
- `/orders` — показать активные заказы
- `/allorders` — последние 20 заказов
- `/chatid` — показать ID текущего чата

Кнопки изменения статуса работают только в чате, указанном в `ADMIN_CHAT_ID`.

## Установка
1. Распаковать архив.
2. В `config.py` указать токен, username менеджера и `ADMIN_CHAT_ID`.
3. Установить зависимости:
   `pip install -r requirements.txt`
4. Запустить:
   `python bot.py`

## Важно
`orders.db` создаётся автоматически рядом с `bot.py`. Не удаляйте его, если хотите сохранить историю заказов.
