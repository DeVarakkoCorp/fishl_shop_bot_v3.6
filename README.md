# Fishl Shop Bot v3.7

Telegram-бот магазина с прайсами, заказами и панелью менеджеров.

## Произвольное количество

- **Крутки** — остаются варианты 1 / 10 / 100 и добавлена кнопка «✏️ Ввести своё количество».
  Для обычного раздела «Крутки» используется текущая цена 24 ₽ за 1 крутку; для «Для 57+ рангов → Крутки» — 30 ₽ за 1 крутку.
- **Диковинки** — покупатель выбирает регион и вводит любое количество. Цена считается по цене за 1 шт. из текущего прайса.
- **Окулы** — покупатель выбирает тип и вводит любое количество. Цена считается по цене за 1 шт. из текущего прайса.
- Допустимое количество: от 1 до 100000.
- Итоговая стоимость автоматически показывается покупателю и менеджеру.

## Печати регионов

В исходном `prices.py` этой версии отдельного прайса на печати регионов нет. Цены для печатей не выдумывались, поэтому автоматический расчёт печатей пока не добавлен.

## Безопасность токена

`config.py` получает `BOT_TOKEN`, `MANAGER_USERNAME` и `ADMIN_CHAT_ID` из переменных окружения. Токен не должен храниться в GitHub.

Для Railway:
- `BOT_TOKEN`
- `MANAGER_USERNAME`
- `ADMIN_CHAT_ID`

Start Command:
`python bot.py`
